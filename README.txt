OSC 6.0 Fire Control: приложение для телефона
==============================================

В архиве:
  index.html              сама страница
  manifest.webmanifest    название и иконки приложения
  sw.js                   офлайн-режим
  icon-*.png              иконки

Как поставить на телефон
------------------------
Приложению нужен адрес с https. Проще всего бесплатный GitHub Pages.

1. Зайдите на github.com, войдите и создайте репозиторий (New repository), например osc6.
   Сделайте его Public.
2. Нажмите "uploading an existing file" и загрузите ВСЕ файлы из этого архива
   (распакуйте его заранее). Нажмите Commit changes.
3. Откройте Settings, затем Pages. В Branch выберите main и папку /(root), нажмите Save.
4. Через минуту появится ссылка вида https://ВАШ-НИК.github.io/osc6/
5. Откройте её в Chrome на телефоне. Нажмите меню ⋮ и выберите
   "Установить приложение" (или "Добавить на главный экран").

После установки иконка OSC 6.0 появится на рабочем столе. Приложение открывается
без адресной строки и работает без интернета. Шрифты подтянутся при первом запуске
онлайн, без них страница выглядит чуть проще, но считает так же.

Обновление: загрузите новый index.html поверх старого. Если приложение показывает
старую версию, закройте его и откройте снова.
